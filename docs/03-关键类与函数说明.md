## 包 `com.ice.guard`

### `IceGuardApp : Application`

**职责**：应用入口，仅做依赖容器初始化，不做任何后台常驻行为。

### `object AxmlParser`

**职责**：自研 AXML 二进制解析器，提取 `<manifest>` 的 package、`<uses-permission>`，

| 成员 | 签名 | 说明 |
|---|---|---|

| `ComponentInfo` | `data class(type, name, exportedExplicit: Boolean?, permission: String?, actions: List<String>)` | 单个组件；`exported` 按"显式声明 → 否则带 intent-filter 即可导出"推导 |
| `ManifestInfo` | `data class(packageName: String?, permissions: List<String>, success: Boolean, error: String? = null, components: List<ComponentInfo> = emptyList())` | 解析结果 |

### `object ComponentAnalyzer`

**职责**：组件暴露面分析——从已安装应用（PackageManager）或 APK（AXML）两种来源
统一提取组件，识别高敏感绑定服务与"对外暴露但无权限门槛"的组件。

| 成员 | 签名 / 值 | 说明 |
|---|---|---|
| `ExportedComponent` | `data class(type, name, exported, permission, actions = emptyList())` | 统一组件描述；`isLauncher` 排除桌面入口 |
| `BINDING_SERVICES` | `Map<String, Pair<String, Int>>` | 8 类 `BIND_*` 权限 → 说明与权重（无障碍 / VPN 70，通知读取 / 输入法 65，设备管理器 60，通话筛查 45…） |
| `fromPackageInfo` | `fun fromPackageInfo(info: PackageInfo): List<ExportedComponent>` | 已安装应用来源；Provider 的读/写权限需**同时**受保护才算有门槛 |
| `fromManifest` | `fun fromManifest(manifest: ManifestInfo): List<ExportedComponent>` | AXML 来源 |
| `findings` | `fun findings(components, owner, launcherActivity = null): List<Finding>` | 生成发现项：绑定服务（45–70 起）+ 暴露组件按类型汇总（Provider 55 / Service 30 / Receiver 25 / Activity 25） |
| `PACKAGE_FLAGS` | `const val` | `GET_ACTIVITIES \| GET_SERVICES \| GET_RECEIVERS \| GET_PROVIDERS` |

**精度设计**：`findings()` 只对"真正能被任意应用触达"的组件报警；
绑定服务按 `distinctBy` 去重（同一应用多个无障碍服务只报一次）。

## 包 `com.ice.guard.core.guard`

安全守护：四条检测通道（安装 / 开机 / 前台 / 无障碍）+ 周期巡检，全部汇入
`AutoResponder` 一条响应管线。详见
[02 · 模块 9](02-核心模块详解.md#模块-9--安全守护coreguard)。

### `GuardModels.kt` 域模型

| 类型 | 说明 |
|---|---|
| `enum class GuardChannel` | 触发通道：`INSTALL` / `UPDATE` / `BOOT` / `FOREGROUND` / `ACCESSIBILITY` / `PERIODIC` / `MANUAL` |
| `enum class GuardVerdict` | 结论：`OBSERVED` / `ALERTED` / `TERMINATED` / `FROZEN` / `FAILED`；`acted` 标记是否真正动手 |
| `data class GuardEvent` | 一条拦截记录：时间 / 包名 / 评分 / 通道 / 结论 / 动作 / `detail`（命令返回与耗时）/ `viaShizuku`；含 `toJson` / `fromJson` |
| `data class GuardPolicy` | 策略：`autoRespond`（默认 **false**）/ `threshold`（默认 65，范围 40–95）/ `terminate` / `freeze` / `watchForeground` / `watchAccessibility` / `guardMode`；`shouldRespond(score)` |

### `object AutoResponder`

**职责**：唯一响应管线。`decide()` 为纯函数（可测），`handle()` 阻塞调用（须在后台线程）。

| 成员 | 签名 | 说明 |
|---|---|---|
| `Decision` | `enum class` | `IGNORE` / `ALERT_ONLY` / `TERMINATE_ONLY` / `TERMINATE_AND_FREEZE` |
| `decide` | `fun decide(score, policy, shizukuReady, forced = false): Decision` | 决策：未达阈值忽略；达阈值未开自动处置只告警；`forced`（用户主动）不受开关限制 |
| `handle` | `fun handle(context, packageName, channel): GuardEvent?` | 完整链路；未达阈值或节流中返回 null（不写日志） |
| `manualRespond` | `fun manualRespond(context, packageName): GuardEvent?` | 用户主动处置，跳过缓存 |
| `invalidate` | `fun invalidate(packageName)` | 安装 / 更新后使缓存分数失效 |

**内部机制**：`auditCache`（10 分钟 TTL，上限 300）、`lastHandled`（30 秒处置节流，
按包名，含过期清理）。处置结果记录实际耗时与逐条命令返回。

### 守护组件

| 组件 | 职责 |
|---|---|
| `class GuardService : Service` | 常驻前台服务（`specialUse` 类型）：挂常驻通知 + 承载 `ForegroundAppWatcher`；`start()` / `stop()` / `sync()` 按策略同步启停 |
| `class ForegroundAppWatcher(context)` | 用 `UsageStatsManager.queryEvents` 按 1 秒轮询前台应用（API 29+ `ACTIVITY_RESUMED`，否则 `MOVE_TO_FOREGROUND`）；`hasPermission()` 检查 AppOps 授权 |
| `class GuardAccessibilityService : AccessibilityService` | 只监听 `TYPE_WINDOW_STATE_CHANGED` 取包名；`onServiceConnected` 同步策略开关；**无任何操作能力** |
| `class BootGuardReceiver : BroadcastReceiver` | 开机 / 应用更新后：重排周期巡检 + 同步守护服务 + 跑一次全量巡检 |
| `class WatchdogWorker : CoroutineWorker` + `object GuardScheduler` | 周期巡检（最小 15 分钟，`KEEP` 策略不重置计时）；失败不重试（下周期自然会再跑） |
| `class GuardActionReceiver : BroadcastReceiver` | 通知「立即终止」按钮；`setPackage` 限定包内广播，外部无法伪造触发 |
| `object GuardSweep` | 全量巡检 + **状态漂移检测**（曾被冻结的应用是否复活）；查询失败时宁可漏报不误报 |
| `object GuardNotifier` | 通知渠道 `ice_guard_alerts`；告警通知带「立即终止」动作（仅在未处置且具备终止能力时）；常驻通知 `ONGOING_ID` |

### `class GuardConfigStore(context: Context)`

守护策略存储，`SharedPreferences("ice_guard_policy")`。
`load()` / `save()` / `update(transform)`（读出 → 改字段 → 写回）。
阈值越界自动收敛到 `40..95`；**读取失败一律回退保守默认值**（自动处置关闭），
绝不因存储损坏而意外开启自动处置。

### `class InterceptLogStore(context: Context)`

| `actions()` | 只取真正执行过处置的记录（`verdict.acted`），供首页"已拦截 N 次" |
