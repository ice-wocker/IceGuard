# 03 · 关键类与函数说明

本文按包路径列出每个关键类的职责与函数签名。标注 `object` 的为 Kotlin 单例，
`data class` 为数据类，其余为普通类。

## 包 `com.ice.guard`

### `IceGuardApp : Application`

**职责**：应用入口，仅做依赖容器初始化，不做任何后台常驻行为。

```kotlin
override fun onCreate()
```

- 调用 `AppContainer.init(this)`；
- 调用 `ShizukuBridge.register()`（用户未安装 Shizuku 时是无副作用的空操作）。

**职责**：自研极简依赖容器（不引入 Hilt / Koin）。单例通过 `lazy` 延迟创建，

| `apkScan` | `ApkScanEngine` | APK 扫描引擎 |
| `environmentCheck` | `EnvironmentCheckEngine` | 环境检测引擎 |
| `disposal` | `DisposalEngine` | 处置引擎 |
| `historyStore` | `ScanHistoryStore` | 体检历史存储 |

## 包 `com.ice.guard.core.rules`

### `enum class RiskLevel(score: Int, label: String)`

| 常量 | score | label |
|---|---|---|
| `SAFE` | 0 | 安全 |
| `LOW` | 20 | 低风险 |
| `MEDIUM` | 50 | 中风险 |
| `HIGH` | 75 | 高风险 |
| `CRITICAL` | 100 | 极高风险 |

| 函数 | 签名 | 说明 |
|---|---|---|
| `fromScore` | `fun fromScore(score: Int): RiskLevel` | 依据分值反查等级：`≤14 安全 / <40 低 / <65 中 / <85 高 / else 极高` |

### `data class Finding`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | `String` | 唯一标识 |
| `title` | `String` | 标题 |
| `detail` | `String` | 详细说明 |
| `level` | `RiskLevel` | 风险等级 |
| `weight` | `Int` | 权重 |
| `category` | `Category` | 分类 |

`enum class Category(display: String)`：`PERMISSION`(权限) / `APK`(安装包) /
`ENVIRONMENT`(环境) / `NETWORK`(网络) / `STORAGE`(存储)。

`fun summary(): String` → `"[${level.label}] $title"`。

### `object PermissionRules`

| 成员 | 签名 / 类型 | 说明 |
|---|---|---|
| `PERMISSION_WEIGHTS` | `Map<String, Int>` | 单权限基础权重表（约 30 项） |
| `ComboRule` | `data class(id, requires: Set<String>, bonus: Int, level: RiskLevel, reason: String)` | 组合规则模型 |
| `COMBO_RULES` | `List<ComboRule>` | 9 条组合规则 |
| `scoreOf` | `fun scoreOf(grantedPermissions: Collection<String>): Int` | 计算 0–100 风险分 |
| `matchedCombos` | `fun matchedCombos(grantedPermissions: Collection<String>): List<ComboRule>` | 命中的组合规则，用于生成报告依据 |
| `weightOf` | `fun weightOf(permission: String): Int` | 反查权限权重，未收录返回 0 |
| `isTracked` | `fun isTracked(permission: String): Boolean` | 是否属于知识库关注范围 |

## 包 `com.ice.guard.core.scanner`

### `object AxmlParser`

**职责**：自研 AXML 二进制解析器，提取 `<manifest>` 的 package 与 `<uses-permission>`。

| 成员 | 签名 | 说明 |
|---|---|---|
| `ManifestInfo` | `data class(packageName: String?, permissions: List<String>, success: Boolean, error: String? = null)` | 解析结果 |
| `parseFromApk` | `fun parseFromApk(apk: File): ManifestInfo` | 从 APK 的 zip 中读取 `AndroidManifest.xml` 并解析 |
| `parse` | `fun parse(input: InputStream): ManifestInfo` | 解析 AXML 输入流 |
| `parseBytes` | `fun parseBytes(bytes: ByteArray): ManifestInfo` | 解析字节数组（测试与复用入口） |

**私有实现**：`StringPool`（按 flags 决定 UTF-8 / UTF-16 解码，带索引缓存）、
`readStringPool()`、`readStartTag()`。常量：`CHUNK_STRING_POOL=0x0001`、
`CHUNK_START_TAG=0x0102`、`CHUNK_END_TAG=0x0103`、`RES_XML_TYPE=0x0003`、
`FLAG_UTF8=0x100`、`ATTR_SIZE=20`。

### `class PermissionAuditEngine(context: Context)`

| 成员 | 签名 | 说明 |
|---|---|---|
| `AppAuditResult` | `data class(packageName, appLabel, isSystem, declaredPermissions: List<String>, score: Int, level: RiskLevel, findings: List<Finding>)` | 单应用审计结果 |
| `auditAll` | `fun auditAll(includeSystem: Boolean = false): List<AppAuditResult>` | 审计全部已安装应用，按分数降序 |
| `auditOne` | `fun auditOne(packageName: String): AppAuditResult?` | 审计单个包名 |
| `buildFindings` | `private` | 生成发现项（高危单权限 + 命中组合） |
| `readablePermission` | `private fun readablePermission(perm: String): String` | 权限名 → 中文可读名 |

### `class ApkScanEngine(context: Context)`

| 成员 | 签名 | 说明 |
|---|---|---|
| `ApkScanResult` | `data class(file: File, manifest: ManifestInfo, sha256: String?, score: Int, level: RiskLevel, findings: List<Finding>)` | 单 APK 扫描结果 |
| `scanCommonDirs` | `fun scanCommonDirs(): List<Finding>` | 扫描常见目录，返回发现项（按权重降序，最多 50 条） |
| `scanOne` | `fun scanOne(apk: File): ApkScanResult?` | 扫描单个 APK（供 UI 详情页使用） |

**私有实现**：`safeScan()`、`scan()`、`collectApks()`（递归，深度 3，上限 200）、`sha256Of()`。
常量：`MAX_FILES=200`、`MAX_FINDINGS=50`、`SKIP_DIRS`（Android/data/obb/cache 等）。

### `class EnvironmentCheckEngine(context: Context)`

| 函数 | 说明 |
|---|---|
| `check(): List<Finding>` | 执行全部 7 项检测，按权重降序返回 |
| `checkRoot(): List<Finding>` | 4 策略交叉 Root 检测 |
| `checkDeveloperOptions(): List<Finding>` | ADB 调试 + 模拟位置 |
| `checkAccessibilityServices(): List<Finding>` | 启用无障碍服务的应用 |
| `checkDeviceAdmins(): List<Finding>` | 活跃设备管理器 |
| `checkUnknownSources(): List<Finding>` | 未知来源安装开关 |
| `checkStorageEncryption(): List<Finding>` | 存储加密状态 |
| `checkScreenLock(): List<Finding>` | 锁屏强度 |

### `class HealthCheckCoordinator`

| 成员 | 签名 | 说明 |
|---|---|---|
| `Progress` | `data class(step: Int, total: Int, label: String)` | 进度回调 |
| `runFullCheck` | `suspend fun runFullCheck(includeApk: Boolean = true, onProgress: (Progress) -> Unit = {}): ScanReport` | 在 IO 线程串行调度各模块并汇总 |

**私有实现**：`runPermissionModule()`、`runEnvironmentModule()`、`runApkModule()`、
`computeModuleScore()`（单模块扣分上限 40）、`computeOverallScore()`（权重 50/30/20）。

## 包 `com.ice.guard.ui`

### `class MainActivity : AppCompatActivity`

首页：展示安全评分、发起体检、展示明细、导出报告、查看历史。

| 函数 | 说明 |
|---|---|
| `onCreate` | 绑定控件、注册 6 个入口点击监听、载入上次报告 |
| `onResume` | `renderPrivilegeSubtitle()` 如实显示当前授权状态 |
| `loadLastReport()` | 从历史读取上次结果，避免每次进入都重扫 |
| `startCheck()` | 用 `lifecycleScope` 启动 `coordinator.runFullCheck()`，实时更新进度 |
| `renderReport(report)` | 评分环动画 + 模块列表 + 操作区 |
| `exportReport()` | `ReportExporter.exportAndShare()` |
| `showHistory()` | 弹窗展示历史记录，支持清空 |

### `class ScoreRingView : View`

自研评分环控件（不依赖图表库，用 Canvas 直接绘制），三层：底环、进度弧（渐变 + 外发光）、
中心文本 + 副标签。

| 函数 | 说明 |
|---|---|
| `setScore(score: Int)` | 设置分值并播放 900ms 缓动过渡动画 |
| `setScoreImmediate(score: Int)` | 直接设置，无动画（初始化 / 列表复用） |
| `onSizeChanged` / `onDraw` | 尺寸计算与绘制 |

渐变配色由 `riskColors(level)` 按风险等级给出（起点色, 终点色）。

### `class FindingAdapter : RecyclerView.Adapter<FindingAdapter.ModuleViewHolder>`

体检发现项（按模块）列表适配器。`submit(modules)` 刷新数据；
点击条目展开/收起详情。

### `object ReportExporter`

| 函数 | 说明 |
|---|---|
| `exportAndShare(context, report)` | 写入私有目录并构造 `ACTION_SEND`（`text/markdown`）经 FileProvider 分享 |
| `exportToFiles(context, report)` | 仅落盘，返回生成的文件路径列表 |

### `class AuditActivity : AppCompatActivity`

应用权限审计详情页。展示全部应用及其评分，支持展开明细；
已授权 Shizuku 时可对单个应用执行处置。

| 函数 | 说明 |
|---|---|
| `loadData()` | IO 线程调用 `permissionAudit.auditAll()` |
| `renderPrivilegeHint()` | 顶部提示授权状态，可点击跳转授权页 |
| `showDisposeDialog(item)` | 处置弹窗；未授权时引导去授权页；不提供批量操作 |
| `confirmAndRun(item, action)` | 破坏性动作标红二次确认 |
| `runAction(item, action)` | 执行处置，Toast 反馈并刷新列表验证生效 |

### `class AppAuditAdapter : RecyclerView.Adapter<AppAuditAdapter.VH>`

应用审计列表适配器，按风险分降序；构造参数 `onDispose` 回调由 Activity 处理弹窗。

### `class ApkScanActivity : AppCompatActivity`

安装包静态扫描页。进入即 `startScan()`，调用 `apkScan.scanCommonDirs()` 并展示结果。

### `class ApkFindingAdapter : RecyclerView.Adapter<ApkFindingAdapter.VH>`

APK 扫描结果适配器（列表项复用 `item_finding` 布局）。

### `class PrivilegeGuideActivity : AppCompatActivity`

权限授权与处置引导页，把「无线调试配对」6 步摊开写清楚，并按 `ShizukuBridge.State`
给出当前该做什么。

| 函数 | 说明 |
|---|---|
| `refresh()` | 刷新状态文案、颜色、按钮可用性 |
| `requestPermission()` | 触发授权，延迟一拍读取结果 |
| `loadDisabledPackages()` | 授权后查询「已停用的应用」，用数据验证处置真的生效 |
| `launchApp(pkg)` | 打开 Shizuku（未安装则跳应用市场） |
| `openWirelessDebugging()` | 打开开发者选项 / 应用详情（多级回退兼容各家 ROM） |

## AIDL 接口 `com.ice.guard.IUserService`

> 对应文件：[IUserService.aidl](../app/src/main/aidl/com/ice/guard/IUserService.aidl)

```aidl
interface IUserService {
    void destroy() = 16777114;                       // Shizuku 约定事务号，必须保留
    String[] exec(in String[] command) = 1;          // 返回 [exitCode, stdout, stderr]
    int getServiceUid() = 2;                         // 服务进程 uid
}
```

命令以数组传入、不拼接字符串，避免注入。
