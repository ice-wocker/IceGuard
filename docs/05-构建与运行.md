## 2. 构建命令

```bash
# 调试版
./gradlew assembleDebug

# 运行单元测试
./gradlew testDebugUnitTest

# 发布版（需自行配置签名）
./gradlew assembleRelease
```

产物位于 `app/build/outputs/apk/`。

### 常用调试命令

```bash
# 安装到已连接设备
./gradlew installDebug

# 查看实际依赖树（用于许可证 / 依赖审计）
./gradlew :app:dependencies --configuration debugRuntimeClasspath

# 查看所有可用任务
./gradlew tasks
```

### 构建配置要点

> 对应文件：[app/build.gradle.kts](../app/build.gradle.kts)

- `namespace` / `applicationId`：`com.ice.guard`
- `versionCode = 4`、`versionName = "1.1.0"`
- `buildFeatures { viewBinding = true; aidl = true }`（ViewBinding + AIDL 编译）
- `release` 开启 `isMinifyEnabled` / `isShrinkResources`，应用 `proguard-rules.pro`
- Java / Kotlin 目标均为 17
- `packaging.resources.excludes` 排除 `META-INF/*.kotlin_module`、`META-INF/DEPENDENCIES`

## 3. 运行方式

### 3.1 作为 Android 应用运行

1. 用 Android Studio 打开仓库根目录（或命令行 `./gradlew installDebug`）。
2. 运行 `app` 模块到 Android 8.0（API 26）及以上的设备 / 模拟器。
3. 首次启动后：

| 操作 | 说明 |
|---|---|
| 点「开始安全体检」 | 串联权限审计 → 环境检测 → APK 扫描，生成百分制评分 |
| 点「应用审计」 | 查看全部已安装应用及其风险评分，逐个展开权限明细 |
| 点「安装包扫描」 | 扫描存储中的 APK 文件并评估风险 |
| 点「守护中心」 | 开关守护模式 / 自动处置 / 阈值，查看拦截日志、立即巡检 |
| 点「权限与处置」 | 查看授权状态 / 走无线调试配对流程 |
| 点「导出报告」 | 生成 Markdown / JSON 并经系统分享 |
| 点「历史记录」 | 查看历史体检记录、清空历史 |

### 3.2 权限授予

- Android 11+ 首次需授予 `QUERY_ALL_PACKAGES` 相关能力（部分 ROM 需手动在设置中允许）。
- Android 13+ 需授予 `POST_NOTIFICATIONS` 才能收到新装高危应用 / 守护告警提醒。
- 安装包扫描在 Android 12 及以下需 `READ_EXTERNAL_STORAGE`。
- 守护的前台唤醒通道需在系统设置中手动授予「**使用情况访问**」特殊权限
  （`PACKAGE_USAGE_STATS`，应用无法自行申请）；未授予时该通道自动跳过。
- 无障碍通道需在系统设置中手动开启 `GuardAccessibilityService`；
  服务只监听窗口状态变化取包名，`canRetrieveWindowContent=false`。

### 3.3 启用「应用处置」（可选）

处置能力需要用户自行安装 [Shizuku](https://github.com/RikkaApps/Shizuku) 并完成一次配对授权：

1. 安装 Shizuku 应用。
2. 「设置 → 关于手机」连点「版本号」7 次，打开开发者选项。
3. 「开发者选项 → 无线调试」开启，点「使用配对码配对设备」记下配对码。
4. 在 Shizuku 应用内选择「通过无线调试启动」，输入配对码完成配对。
5. 回到 IceGuard 的「权限与处置」页，点「请求授权」。

授权后获得的是 **shell（ADB，uid 2000）级权限**，可执行 `am force-stop`（**秒级终止进程**）/
`pm disable-user` / `pm uninstall` / `pm clear` / `pm revoke`，但**读不到其他应用进程内存**。

授权同时是开启「自动终止」的前提：未授权时守护中心会直接拦下开关并指路，
而不是让用户误以为"开了就安全"。

## 4. 测试

### 4.1 单元测试

```bash
./gradlew testDebugUnitTest
```

**69 个单元测试**，覆盖 6 个测试类：

| 测试类 | 用例数 | 覆盖内容 |
|---|---|---|
| `PermissionRulesTest` | 16 | 评分模型：组合命中、阈值边界、误报控制、规则合法性 |
| `AxmlParserTest` | 22 | 解析器：真实样本、组件级解析、健壮性、异常输入、流/字节一致性 |
| `ComponentAnalyzerTest` | 11 | 组件暴露面：误报控制、绑定服务识别、启动器排除 |
| `AutoResponderTest` | 10 | 守护决策：阈值边界、授权与否、用户主动处置 |
| `ShellResultTest` | 5 | 成败判定只看 exitCode、摘要回退、超时编码 |
| `InstallMonitorTest` | 5 | 告警阈值行为锁定（防骚扰） |

测试文件位于 `app/src/test/java/com/ice/guard/`。
守护决策链路的用例刻意锁死的是「什么情况下**不会**动手」：
默认策略下即使评分 100 也只告警；未授权 Shizuku 时绝不尝试终止。

### 4.2 AXML 真实样本

> 对应文件：`app/src/test/resources/real_manifest.axml`

该夹具是 AAPT2 编译 IceGuard 自身产生的二进制清单（**17940 字节，含 25+ 个组件**），
期望值取自 `aapt2 dump xmltree` 输出，作为权威对照基准——
确保解析器在真实 AAPT2 输出上可用，而非仅通过手工构造的理想数据。

复现方式：

```bash
unzip -o app-debug.apk AndroidManifest.xml -d /tmp        # 即为夹具本身
aapt2 dump xmltree --file AndroidManifest.xml app-debug.apk   # 权威对照
```

### 4.3 健壮性用例

覆盖：空数据、过短数据（4 字节）、非 AXML 数据（ZIP 头 "PK"）、
逐段截断样本（16 / 64 / 256 / 1024 / 3000 / 6000 字节）、
字节翻转样本（破坏字符串池区域）——验证解析器在任何输入下都不崩溃。

## 5. CI / CD

### 5.1 Android CI

> 对应文件：[.github/workflows/build.yml](../.github/workflows/build.yml)

- **触发**：push / PR 到 `main`、`master`，或手动 `workflow_dispatch`。
- **流程**：
  1. checkout → 安装 JDK 17（temurin）→ 安装 Android SDK → 配置 Gradle；
  2. `./gradlew testDebugUnitTest`；
  3. `./gradlew assembleDebug`；
  4. `./gradlew assembleRelease`（**专门验证 R8 规则没有裁掉靠反射实例化的类**）；
  5. 校验 APK 产物存在，上传 debug APK 制品；
  6. 失败时上传构建报告。

### 5.2 Release 自动发版

> 对应文件：[.github/workflows/release.yml](../.github/workflows/release.yml)

- **触发**：打 tag（`v1.0.0` / `v1.0.0-beta.1`）或手动指定已有 tag。
- **流程**：checkout 指定 tag → 构建环境 → 测试 → `assembleDebug` →
  计算 SHA-256 校验和 → 用 `softprops/action-gh-release` 创建 / 更新 GitHub Release，
  附带 APK 与 `.sha256` 文件；含 `-` 的 tag 自动标记为 prerelease。

> 注：发版流水线当前构建并发布的是 **debug APK**（用于便于安装验证），
> release 构建仅在 CI 中用于验证 R8 规则。

## 6. 构建网络环境（国内镜像）

若访问 Gradle 官方源与 Google Maven 受限，本项目已默认配置国内镜像：

- **仓库镜像**（见 [settings.gradle.kts](../settings.gradle.kts)）：使用阿里云
  `gradle-plugin` / `google` / `public` / `central` 镜像，`RepositoriesMode.PREFER_SETTINGS`。
- **Gradle 发行版镜像**（见 [gradle-wrapper.properties](../gradle/wrapper/gradle-wrapper.properties)）：
  使用腾讯云 `mirrors.cloud.tencent.com/gradle/gradle-8.9-bin.zip`。

`gradle.properties` 关键配置：`org.gradle.jvmargs=-Xmx3072m`、`parallel=true`、
`caching=true`、`android.useAndroidX=true`、`android.nonTransitiveRClass=true`。

## 7. 验证「不联网」特性

本项目不申请 `INTERNET` 权限，可在编译产物上自行验证：

```bash
aapt2 dump permissions app/build/outputs/apk/debug/app-debug.apk
```

预期只看到 `QUERY_ALL_PACKAGES`、`READ_EXTERNAL_STORAGE`（maxSdk 32）、
`POST_NOTIFICATIONS`，**不含 `android.permission.INTERNET`**。
