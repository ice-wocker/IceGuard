## 项目一句话简介

IceGuard 通过**审计已安装应用的权限组合**、**检测设备环境风险**、**静态分析本地安装包**，
给出一个可解释的安全评分。所有分析都在设备本地完成——**应用本身不申请 `INTERNET` 权限**，
这一点可在编译产物中验证。

## 设计原则

1. **能力边界明确**——只做技术上确实能做到的事，不做无法验证的承诺。
2. **零网络请求**——不申请 `INTERNET` 权限，数据不可能外传。
3. **判定依据可解释**——每个评分都能追溯到具体规则，不给出黑箱结论。
4. **代码完全开源**——可自行审计每一条判定逻辑。
5. **业务逻辑零第三方依赖**——评分引擎、AXML 解析器、报告序列化、界面动效均为自研。

## 功能一览

| 模块 | 能力 | 实现方式 |
|---|---|---|
| 应用权限审计 | 枚举已安装应用，评估权限组合风险 | `PackageManager` + 自研组合规则引擎 |
| 安装包静态扫描 | 解析本地 APK 的清单（权限 + 组件），评估风险 | 自研 AXML 二进制解析器 |
| 设备环境检测 | Root 痕迹、危险设置、无障碍服务、设备管理器 | 多策略交叉探测 + 系统设置读取 |
| 安全体检 | 一键串联全部分析，生成百分制评分 | 加权汇总模型 |
| 报告导出 | Markdown / JSON 格式 | 自研序列化 |
| 安全守护（四条检测通道） | 安装/更新、开机自检、前台唤醒、无障碍事件，事件一到即判定处置 | 广播 + WorkManager + UsageStats |
| 秒级终止（可选授权） | 亚秒级 `am force-stop` + 按策略 `pm disable-user` 冻结 | Shizuku（ADB 级权限） |
| 应用处置（可选授权） | 终止 / 停用 / 卸载 / 清除数据 / 撤销权限 | Shizuku（ADB 级权限）`pm` 命令 |
| 组件级清单分析 | 解析四类组件与 `exported`，识别暴露面与内置高敏感服务 | 自研 AXML 解析器 + PackageManager |
| 安装来源与签名检测 | 侧载识别、调试标志、证书 SHA-256 | PackageManager + InstallSourceInfo |
| 拦截日志 | 每次判定与处置的命令返回全部留痕 | 本地 SharedPreferences |

## 技术栈速查

- **语言**：Kotlin 1.9.24，JDK 17
- **构建**：Gradle 8.9 + AGP 8.5.2
- **Android**：compileSdk 34 / minSdk 26 / targetSdk 34
- **架构**：单 `app` 模块，分层（UI / core / data / di）
- **UI**：View 体系（AppCompat + RecyclerView + ConstraintLayout），ViewBinding
- **异步**：Kotlin Coroutines；周期任务用 WorkManager
- **可选提权**：Shizuku 13.1.5（shell / ADB 级权限）
- **版本**：1.1.0（versionCode 4）

## 「1 秒终止」的能力边界

这是本项目最容易被误解的一点，因此在首页就写明：

- **终止是真的**：`am force-stop` 经 Shizuku 以 shell 权限执行，亚秒级结束目标进程；
  再追加 `pm disable-user` 可使其无法自动重启。
- **"监控到病毒发作"做不到**：Android 沙箱隔离了应用间观测，第三方应用看不到
  其他应用的行为与内存。
- **所以本项目提供的是「事件驱动的秒级响应」**：在安装、更新、开机、
  前台唤醒、周期巡检这些**可观测事件**发生时立即判定与处置。
  瓶颈在**检测**，不在**终止**。

任何宣称能在非 Root 手机上"实时监控病毒行为并 1 秒击杀"的产品，
要么依赖 Root，要么在夸大其词。

本工具的评分基于权限组合与设备环境的**启发式评估**，用于提示用户关注方向，
